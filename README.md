# Isaias Agravante Portfolio Website

Personal portfolio website for Isaias Agravante, built from scratch with plain HTML, CSS, and JavaScript.

## Features

- Responsive one-page layout
- Light and dark mode toggle
- Live Manila clock in the top bar
- Projects, overview, experience, education, certifications, skills, and contact sections

## Tech Stack

- HTML
- CSS
- JavaScript

## Files

- `index.html` - main page structure
- `styles.css` - site styling and theme support
- `script.js` - theme toggle and live clock

## Local Use

Open `index.html` in a browser, or serve the folder with any static file server.

## Deployment

This site can be deployed to Cloudflare Pages, GitHub Pages, or any static hosting platform.
